# TechTalent 🚀
### AI-Powered IT Career Development and Recruitment Platform

TechTalent is a web-based IT career development and recruitment platform designed to connect talented IT job seekers with companies and recruiters. The platform provides tools to simplify recruitment, improve job searching, and support professional career development.

## 🌟 Project Overview

TechTalent aims to create a centralized recruitment environment where job seekers can discover career opportunities, build professional CVs, and connect with employers, while recruiters can manage job vacancies and find suitable candidates.

## ✨ Main Features

### 👨‍💻 Job Seeker
- User registration and secure login
- Create and manage professional profiles
- Browse available IT job vacancies
- Apply for job opportunities
- Create and manage CVs
- CV analysis and ATS compatibility support
- Identify missing skills and improve career readiness

### 🏢 Employer / Recruiter
- Employer registration and login
- Manage company profiles
- Post and manage job vacancies
- View job applications
- Find suitable IT candidates

### 🛡️ Administrator
- Manage platform users
- Manage job vacancies
- Monitor platform activities
- Manage community reviews

### 📄 CV Studio
- Professional CV templates
- CV creation and editing
- Existing CV information extraction
- Missing skill detection
- ATS compatibility checking

## ⚙️ Installation and Setup

1. Install WAMP Server.
2. Download or clone this repository.
3. Copy the project folder into the WAMP `www` directory.
4. Start Apache and MySQL services.
5. Open phpMyAdmin.
6. Create the required MySQL database.
7. Import the project's database SQL file.
8. Configure the database connection settings in the project.
9. Open your browser and access the project through localhost.
